I run engineering at **[Xentra](https://my.xentra.kz)** — an electronic document management and digital signature platform for the Kazakhstani market.

That means legally binding documents, ЭЦП, and integrations with государственные системы (Egov, ЭСФ, НУЦ) — a domain where a bug isn't a UI glitch, it's an invalid signature on a real contract. Most of the hard problems here aren't in the framework layer: they're in cryptography edge cases, undocumented state APIs, idempotency, and making a distributed system behave predictably when a third-party service goes down mid-transaction.

I still write production code. I just spend more time now on architecture, hiring and the boring parts that decide whether a product survives its second year.
