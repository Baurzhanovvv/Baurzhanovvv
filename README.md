I build server-side systems in **TypeScript / NestJS** and run them on **Kubernetes**.
Most of my work sits at the intersection of distributed backends and **Kazakhstani government systems** — ЭЦП (digital signature), ЭДО, Egov and ЭСФ integrations. It's a narrow domain with very little documentation, which is exactly what makes it interesting.

I think in terms of system design, not just code: module boundaries, failure modes, race conditions, what happens at 3 a.m. when a queue backs up.

- 🏗 Currently building **[TradeBroker](https://tradebroker.kz)** — B2B trading platform with e-signature and document workflow
- 👥 Leading a small dev team, still writing production code daily
- 📚 Currently going deeper into **CI/CD, testing culture and RabbitMQ**
- 💬 Ask me about **NestJS architecture, Kubernetes, Redis/BullMQ, or Kazakh gov API integrations**
